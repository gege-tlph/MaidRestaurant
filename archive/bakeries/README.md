# Bakeries compatibility archive

The Bakeries compatibility sources are intentionally archived for the Fabric
1.21.11 port. No verified 1.21.11 Fabric Bakeries artifact/API is available in
the migration workspace, so the old adapters live under this archive instead
of the active source set and are not part of the development JAR.

Restore this compatibility only after a matching Fabric 1.21.11 artifact has
been verified against the adapter imports and runtime block/entity behavior.
