首个 CurseForge 发布版本 / First CurseForge release.

### 变更 / Changes

- 依赖的东方小女仆 Tsumugi 从 0.8.4（预发布）升到 0.8.8 正式版，最低要求随之收紧为 0.8.8。
  Bumped Touhou Little Maid: Tsumugi from the 0.8.4 prerelease to the 0.8.8 stable release; the minimum requirement moves to 0.8.8 with it.
- 与 0.8.8 的可食用方块 AI 对齐：补回上游新增的偷取准入判定与目标保持机制。此前版本的整方法替换会静默丢掉这两项，导致女仆在目标间反复切换。
  Realigned with 0.8.8's edible-block AI: the new steal gate and target-hold are applied again. The previous whole-method replacement silently dropped both, which let maids keep re-picking targets.
- 模组显示名改为 Maid Restaurant: Tsumugi。
  The mod display name is now Maid Restaurant: Tsumugi.
- 发布的 JAR 内现已附带 BSD-3-Clause 许可证副本。
  The published JAR now ships a copy of the BSD-3-Clause license.

### 依赖 / Dependencies

- Minecraft 1.21.11 · Fabric Loader 0.18.1+ · Java 21
- 必需 / Required: Fabric API、[Touhou Little Maid: Tsumugi](https://www.curseforge.com/minecraft/mc-mods/touhou-little-maid-tsumugi) 0.8.8+、[Kaleidoscope Cookery Refabricated](https://www.curseforge.com/minecraft/mc-mods/kaleidoscope-cookery-refabricated)
- 可选 / Optional: [Farmer's Delight Refabricated](https://www.curseforge.com/minecraft/mc-mods/farmers-delight-refabricated)、[Patchouli (1.21.11 Fabric 维护版)](https://github.com/gege-tlph/Patchouli/releases/latest)
